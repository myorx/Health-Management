# 健康信息管理系统

一个课程项目：使用 JavaFX 构建桌面客户端，通过本机 TCP 服务端保存和查询健康记录。用户可注册、录入身高、体重、步数和睡眠时长，并按日期查看记录、图表与年度统计；管理员界面提供用户和记录查看功能。

> 项目定位：用于学习 Java 桌面开发、Socket 通信与 SQLite。当前实现是教学原型，请勿接入公网或录入真实敏感健康数据。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `demo/` | JavaFX 桌面客户端及 FXML 界面 |
| `server/` | TCP 服务端与 SQLite 数据读写 |

两个目录现在直接包含源码，不再依赖无法在 GitHub 展开的本地 Git 子仓库引用。

## 环境要求

- JDK 17
- Maven 3.8 或更新版本
- 可运行 JavaFX 的桌面环境

项目依赖由 Maven 下载，包括 JavaFX 17.0.2、SQLite JDBC 3.34.0 和 Gson 2.8.6。首次构建需要联网。

## 本地运行

在两个终端中，按顺序启动服务端和客户端：

```bash
# 终端 1
cd server
mvn clean compile exec:java
```

```bash
# 终端 2（从仓库根目录进入）
cd demo
mvn clean javafx:run
```

服务端监听 `1234` 端口；客户端连接 `127.0.0.1:1234`，所以两者需要在同一台电脑运行。服务端使用当前工作目录中的 `data.db`；按上面的命令从 `server/` 启动时，实际位置是 `server/data.db`。如果该文件不存在，服务端会创建空数据库和表，随后可在客户端注册账号并录入测试数据。

## 迁移旧数据

如果要继续使用旧电脑上的记录，请先停止服务端，将原来的 `data.db` 备份并复制到本项目的 `server/data.db`，再从 `server/` 启动服务端。无需修改数据库中的绝对路径；数据库文件已被 Git 忽略，不会随正常提交上传。复制后可用 `git status` 确认它未进入待提交文件列表。不要把数据库或登录密码放进仓库。

## 已知限制

- 当前客户端与服务端使用本机 TCP 明文通信，密码也按原课程实现存储；**不要复用常用密码或输入真实个人健康信息**。
- 客户端在服务端不可用时会持续尝试连接，因此请先启动服务端。
- 这是原课程作品的归档整理，尚无自动化测试；运行前需要自行安装 JDK 和 Maven。
