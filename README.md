# 健康信息管理系统

基于 JavaFX、Socket 和 SQLite 的桌面应用，提供健康记录管理、数据查询与统计展示功能。客户端与服务端在同一台电脑上运行，适合学习桌面界面、网络通信和数据持久化。

## 功能

- 用户注册与登录
- 按日期录入、查询、修改和删除身高、体重、步数及睡眠记录
- 查看健康数据图表和年度统计
- 管理员查看用户及其健康记录

## 技术栈

| 组件 | 技术 |
| --- | --- |
| 桌面客户端 | Java 17、JavaFX 17 |
| 服务端 | Java 17、TCP Socket |
| 数据存储 | SQLite |
| 构建工具 | Maven |

## 项目结构

```text
Health-Management/
├── demo/      # JavaFX 客户端
└── server/    # TCP 服务端与 SQLite 数据访问
```

## 快速开始

准备 JDK 17、Maven 3.8 或更高版本，以及可运行 JavaFX 的桌面环境。首次构建需要联网下载依赖。

在仓库根目录打开两个终端，先启动服务端，再启动客户端：

```bash
# 终端 1：服务端
cd server
mvn clean compile exec:java
```

```bash
# 终端 2：客户端
cd demo
mvn clean javafx:run
```

服务端监听 `1234` 端口，客户端连接 `127.0.0.1:1234`。首次启动服务端时，会在 `server/data.db` 创建数据库和所需数据表。启动客户端后可注册账号并录入数据。

## 本地数据

数据库保存在 `server/data.db`，该文件已被 Git 忽略。运行服务端时请保持工作目录为 `server/`，以确保数据库位置一致。不要将数据库、账号密码或真实个人健康信息提交到仓库。

## 使用范围

当前实现使用本机 TCP 明文通信，并以明文保存密码。请仅在本机学习和演示，不要开放服务端端口、复用常用密码或存储真实敏感数据。
